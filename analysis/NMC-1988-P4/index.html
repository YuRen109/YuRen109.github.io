What We Learned

  1. If a differentiable function on tends to as , it attains a global minimum.
    If its derivative has exactly one real root, that root must be the global minimizer.

  2. A real polynomial of odd degree has an odd number of real roots, counted with multiplicity.
    If its derivative is strictly positive at every real root, then the real root is unique.

  3. When the minimum of a function occurs at a critical point, the equation obtained by setting the derivative equal to zero may simplify the value of the original function at that point.
