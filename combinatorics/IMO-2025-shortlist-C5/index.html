The construction uses decreasing blocks of even-indexed and odd-indexed terms, arranged so that inversions between indices of the same parity dominate those between indices of opposite parity.

What We Learned

  1. Counting by Injection

    To prove an inequality between the cardinalities of two finite sets, it is often useful to construct an injection from the first set into the second.

    More generally, if a finite set can be partitioned into disjoint subsets, each of which admits an injection into a set , then its cardinality is at most .

  2. Classification by Congruence Classes

    When a problem involves the parity of differences between indices, congruences modulo may provide a more useful classification than parity alone.

    In particular, if is even, then the parity of depends on the residue class of modulo .

  3. Using Intermediate Indices

    Given an inversion , an intermediate index may allow us to associate it with a shorter inversion.

    The choice of the intermediate index must preserve the required inequality between the corresponding terms, while also satisfying the desired parity condition.

  4. Block Constructions

    When constructing sequences with prescribed combinatorial properties, arranging terms into blocks can make the relevant quantities easier to count.

    In this problem, the decreasing blocks of even-indexed and odd-indexed terms allow the number of even inversions to dominate the number of odd inversions.

  5. Asymptotic Sharpness

    To show that a constant in an inequality is optimal, it is not necessary to construct an example attaining equality.

    It suffices to construct a family of examples for which the relevant ratio approaches that constant arbitrarily closely.

    In this problem, the construction shows that the constant in is optimal.
